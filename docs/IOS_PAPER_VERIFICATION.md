# iOS paper companion verification

Reference: [Openlist iOS companion v2 “Paper”](https://claude.ai/artifact/LgNMJgyqvGEyutE7tLLMoV), inspected in the integrated browser on 1 October 2026.

## Acceptance

- Warm canvas, white cards, serif screen titles, neutral ink controls, task metadata below titles, grouped Today sections and progress.
- Today, Inbox, Lists and Work remain reachable from the floating dock. Preserve existing timeline, capture, task detail, work and undo flows.
- Long right swipe adds the task to Today while preserving its due date. Repeating it is idempotent.
- Short right swipe exposes two compact actions. Both are configurable in Settings and persist across launches. Defaults: Move to list and Star.
- Left swipe reveals Delete; a long left swipe moves the task to recoverable Trash. Both have Undo.
- Lists offers Cards and Tasks. Tasks combines active lists, including Inbox, shows provenance, supports multiple list filters, and uses the same task actions.
- List documents retain headings and body notes, with independent stored section/task folds and subtask progress. Task detail exposes its parent context and navigation; archived tasks cannot newly plan for Today.
- Verify ordinary scrolling, saved state, archived/deleted list filters, light/dark, Reduce Motion, and large Dynamic Type.

The user's swipe instructions override the older gesture wording in the reference. The implementation keeps the app's real task library and calendar data, so counts and copy differ from the static reference. The source model and CloudKit schema are unchanged.

## Final result

Five implementation passes each received five scoped verification loops. The further browser interaction audit found and led to corrections for document rendering/disclosure, parent-task navigation, archived Today eligibility, and completed orphan visibility. The final pass passed 135 hosted tests and 15 UI executions across iPhone 18 Pro and iPhone SE, with no failures, retries or skips in those runtime runs. All 204 app and 28 widget sources passed typechecks in Debug/Dev/Release, and all 19 built-bundle checks passed. The application source remained frozen throughout runtime verification.

Pass 4's complete light/dark/Reduce Motion/XXXL journeys, native task gestures, and pixel-verified Home/Lock widget galleries remain recorded below. Pass 5 reruns the affected document, detail, navigation, gesture and filtering flows; widget source is unchanged and its system galleries were not rerun in pass 5. Earlier build and full-suite failures are preserved alongside their corrections; a new full-suite run is not claimed.
