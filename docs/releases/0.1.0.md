The first open-source release of Openlist: a local-first tasks and notes app for macOS, licensed under MIT.

## Requirements and installation

- **Apple Silicon Mac (M1 or newer), macOS 26.5 or later.** Intel binaries are not included.
- Download `Openlist-0.1.0-macos-arm64.dmg`, open it, and drag `openlist.app` to Applications. A ZIP is also available.
- The app and disk image are Developer ID signed and notarized by Apple.
- Launch Openlist once before adding the Today, Summary or Lists widgets.
- `SHA256SUMS.txt` contains checksums for both downloads.

## Included

- Rich task documents with nested tasks, notes, headings, lists, code and inline images.
- Due dates, reminders, repeating tasks, labels, priorities and stars.
- Inbox, Today, search, command palette, menu bar capture and global quick-add.
- Local SwiftData storage, Markdown export and desktop widgets.
- Public source, contribution guidance and automated build/release checks.

## Current scope

This initial release focuses on personal, local use. It has no cloud sync, accounts or collaboration. Native notification delivery, global shortcuts and widgets depend on macOS permissions and configuration. No automatic updater is included; install updates from GitHub Releases after quitting the app.
