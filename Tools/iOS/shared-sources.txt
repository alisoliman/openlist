# only (synchronized folders ignore directories and globs). The iOS app and
# widget also own Shared/ and SharediOS/ wholesale, and their own folders.
#
# This is the one list to edit. `python3 Tools/add-ios-targets.py` writes it
# into the project's exception sets (don't tick target membership in Xcode's
# File inspector instead); Tools/run-ios-core-checks.sh fails while the two
# disagree, then type-checks what the project compiles. Only files that are
# Foundation/SwiftData/UIKit-portable belong here: the Mac UI (Views/, Editor/,
# most of Next/) and AppKit services stay Mac-only.
